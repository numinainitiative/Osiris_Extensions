Trophies 0.1.2 supports optional edition page sharing in Osiris Beta 0.0.56.

Linked editions use the same catalogue, settings and earned trophies. The card, editor, Stats snapshot and sync use the shared source profile, retaining Steam/Xbox progress when a local edition is linked. Sharing previews remain staged until Save. Unlinking or removing the source edition preserves progress in the surviving profile.

Update Osiris to Beta 0.0.56 to enable Share page. Older hosts retain independent per-game storage. No account or credential changes are required.
