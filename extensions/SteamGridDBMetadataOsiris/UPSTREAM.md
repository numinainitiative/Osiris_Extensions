# Provenance

This extension is an original Numina Initiative implementation for Osiris.

- It does not derive from the unlicensed `cooperate/SteamGridDBMetadata`
  Playnite extension.
- The network contract is based on the public SteamGridDB API v2 and the
  official MIT-licensed `SteamGridDB/node-steamgriddb` client documentation.
- It references the MIT-licensed Playnite SDK supplied by Osiris.
- It does not redistribute SteamGridDB artwork. Artwork is requested at runtime
  with the user's own API key.
