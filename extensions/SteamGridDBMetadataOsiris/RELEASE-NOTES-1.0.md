# SteamGridDB Metadata 1.0

First public release of the original SteamGridDB Metadata provider for Osiris.

## Features

- Browse and download SteamGridDB covers, heroes, logos, icons, and related
  horizontal-library artwork.
- Browse static and animated results with paginated manual selection.
- Apply adult-content and humorous-artwork visibility globally.
- Choose the same or a different ranked image for related Osiris media roles.
- Store a user-supplied SteamGridDB API key through the extension settings
  contract; no API key is bundled or logged.
- Remove SteamGridDB completely as an Osiris media source when the extension is
  disabled or uninstalled.

The extension is an independent MIT-licensed implementation using the public
SteamGridDB API v2. SteamGridDB is a third-party service and is not affiliated
with Osiris or Numina Initiative.
