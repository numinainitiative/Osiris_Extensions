GameGallery 2.0.6 adds edition page mirroring for Osiris Beta 0.0.57.

The Gallery page uses the selected source edition when its mirror is enabled. Disabling the mirror retains an independent copy through Osiris. Game identities and native session tracking remain per edition.

This compatibility release derives from the checksum-verified public 2.0.5 package, retaining its licenses and features. The optional bridge preserves independent behaviour on older hosts. Update Osiris before enabling mirrors.
