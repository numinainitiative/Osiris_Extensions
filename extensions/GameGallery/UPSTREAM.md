# Game Gallery

Game Gallery is the Numina Initiative-maintained fork of darklinkpower's MIT-licensed
Steam Store Screenshots Viewer.

The fork preserves the original GUID while using the Osiris catalogue identity
`GameGallery_8e77fe31-5e62-41e2-8fa2-64844cfd5b6b`. Keeping the GUID and existing
installed folder lets Osiris installations retain their Steam matches and
extension data while moving from the legacy module to `GameGallery.dll`.

The unified gallery is intended to present Steam screenshots and trailers in
one card and obtain both from the same cached Steam app-details response.

Upstream: https://github.com/darklinkpower/PlayniteExtensionsCollection
