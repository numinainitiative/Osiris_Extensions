# Game Gallery 2.0.2

- Restores Game Gallery's settings support so Osiris can render the General
  settings page correctly instead of presenting empty extension categories.
- Adds the Cinematic expanded-media experience while preserving Full screen as
  the default for existing profiles.
- Improves screenshot and trailer loading, transitions, caching, cancellation,
  and memory cleanup.
- Keeps the existing extension identity and data paths so version 2.0.1 updates
  in place without losing settings or gallery data.
