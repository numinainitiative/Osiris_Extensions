Screenshots Gallery 0.1.0

- Collects newly saved Windows + Print Screen images while Osiris tracks exactly one running game, keeping Windows originals unchanged.
- Stores copies in that game's Screenshots folder and shows its gallery only when images exist.
- Provides the Game Gallery layout, capture dates, cinematic/full-screen viewing and keyboard navigation.
- Adds per-game enable controls and a six-column thumbnail manager; saved deletions are recoverable in Screenshots/Deleted.
- Uses the supplied coloured Screenshots Gallery artwork. No personal screenshots or profile data are packaged.

Requires Osiris Beta 0.0.50 or newer for the game-details and editor integration.
