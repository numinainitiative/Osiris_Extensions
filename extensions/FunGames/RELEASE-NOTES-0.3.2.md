# Fun Games 0.3.2

Initial public release for Osiris Beta 0.0.53 or newer.

- Fun Games hub with a Roulette poster and Play action.
- Horizontal roulette with wider title cards, centred selection and eased spins.
- Eight random library games by default, with sample choices for empty libraries.
- Create and save named roulettes with 2–32 options and optional descriptions.
- Select saved roulettes from the toolbar; add, edit or delete through Manage
  Roulettes. Deletion requires confirmation and keeps a backup.
- Import and export portable .roulette.json files. Imports open for review and
  explicit Save; existing roulettes are never silently replaced.
- Larger winner popup with confetti, keyboard dismissal and nested Back support.

No wagers, automatic game launches or changes to game tracking. Exported files
contain roulette names and option text, not local game IDs or library artwork.
