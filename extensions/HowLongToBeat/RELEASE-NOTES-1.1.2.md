# HowLongToBeat 1.1.2

This release refines the completion-time card so it sits more naturally beside
Osiris's built-in Game Details cards.

- Matches the Main Story and Main + Extras row backgrounds to the Overview body.
- Uses true-black spacing between completion-time rows.
- Retains the slightly raised Completionist surface for a subtle visual finish.
- Preserves locally stored completion estimates, selected time profiles, played-
  time progress, per-game matching, and offline availability.
