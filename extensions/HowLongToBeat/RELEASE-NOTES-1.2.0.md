# HowLongToBeat 1.2.0

This release adds a complete global HowLongToBeat library page for Osiris.

- Browse every local game in a virtualized Icon, Game, and How Long To Beat
  table with a fixed native Osiris header and search box.
- Compare local playtime with stored Main Story, Main + Extras, and
  Completionist estimates on one proportional timeline.
- Sort by title, time played, or longest completion estimate, and optionally
  show only games that have been played.
- Open a game's Details page directly from its title and use the Osiris logo
  only when that game has no local icon.
- Update already-matched games from the page or extension settings while work,
  cancellation, and completion appear in Osiris's standard bottom panel.
- Keep the global page offline-first: opening, searching, sorting, and filtering
  use only locally stored HLTB data and never fetch or stream records.
