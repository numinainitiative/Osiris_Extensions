# Stats 0.1.0

- Adds collapsible Weekly Stats and All Time Stats dashboards backed by the Osiris library.
- Adds magnetic per-category layout editing with saved, fixed-grid positions.
- Adds top-played, last-played, platform-library, and status lists alongside playtime, activity, collection, storage, age, session, streak, and game highlights.
- Adds optional HowLongToBeat and Exophase categories that appear only while their matching extensions are installed.
- Reads extension statistics through local, read-only bridges without triggering network synchronization.
